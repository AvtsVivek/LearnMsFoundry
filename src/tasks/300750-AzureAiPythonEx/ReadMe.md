
This example uses azure-ai-projects python framework SDK

You'll notice that in this example we used the Azure AI Projects SDK. This SDK is designed around the idea of projects and agents that already exist in Microsoft Foundry. Here, we define the agent in the UI and from Python we simply retrieve it and run it.

The code is synchronous, very straightforward, and it maps closely to what you see in the Foundry interface to what you see here. 

If you want simple production ready code tht mirrors the foundry UI, this azure ai projects SDK is a great fit.

Microsoft also provides what is called Microsoft Agent Framework SDK, MAF

If you wnat to build a more dynamic highly agentic systems, tools and concurrency, the Ms agent framework(aka MAF) SDK is a great fit.
