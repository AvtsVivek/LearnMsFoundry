
This example uses Ms agent framework(aka MAF) SDK 

To run the example, ensure a file .env in the directory where you have the python file. 
.env file should not pushed to sourced code.

Let that file have the following text.

```txt
AZURE_AI_PROJECT_ENDPOINT=https://vivek-foundry-core-env-subdomain-o7a07v.services.ai.azure.com/api/projects/vivek-foundry-core-env-project-o7a07v
AZURE_AI_AGENT_NAME=vivek-gpt-5-mini-agent-twenty-five
```

Get the end points and agent name from the portal, after your deployment of your resources
