![Validate Prerequisites](images/51_50_ValidatePrerequisites.png)

3. Then install Ubuntu. First check for existing installations.

![Existing installations](images/51_60_Wsl_List_Before.png)

4. Install Ubuntu [as mentioned here.](https://learn.microsoft.com/en-us/windows/wsl/install#change-the-default-linux-distribution-installed) 

```ps
wsl.exe --install -d Ubuntu
```
